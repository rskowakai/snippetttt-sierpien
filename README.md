# LegalTech Pro - Secure Document Management Platform

## Overview

LegalTech Pro is a comprehensive legal document management platform built with a modern TypeScript stack. It provides secure document handling, AI-powered document analysis, and real-time collaboration tools tailored for legal professionals.

## Key Features
- **Secure Document Handling**: Strong encryption and secure storage for sensitive legal documents.
- **AI-Powered Analysis**: Automated document analysis with natural language processing.
- **Real-Time Collaboration**: Collaborate with team members seamlessly.

## Technologies Used
### Frontend
- React 18
- TypeScript
- Vite
- Tailwind CSS

### Backend
- Supabase
- PostgreSQL with Drizzle ORM
- Edge Functions written in Deno/TypeScript

## Getting Started
### Prerequisites
- Node.js
- Git

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/rrsartgit/snippetttt-sierpien.git
   cd snippetttt-sierpien
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Set up environment variables in a `.env` file:
   ```env
   SUPABASE_URL=
   SUPABASE_KEY=
   DATABASE_URL=
   ```

4. Run the development server:
   ```bash
   npm run dev
   ```

5. Access the application at `http://localhost:3000`.
